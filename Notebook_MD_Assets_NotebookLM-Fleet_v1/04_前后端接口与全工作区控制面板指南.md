# 04 · 前后端接口与全工作区控制面板指南

## 一、双栏全工作区 Web 控制台（`web/index.html`）

控制面板采用无构建依赖的单页 HTML + 暖纸质感（Warm Editorial）样式，监听 `http://127.0.0.1:8765`，并在 `GET /` 响应头设置 `Cache-Control: no-store, no-cache, must-revalidate` 防止浏览器缓存旧页面。

### 1. 左侧常驻全工作区侧边栏
- **三根目录切换**：
  - `工作目录`（默认，`WORKSPACE_ROOT=<WORKSPACE_ROOT>`）
  - `Google云盘`（`DRIVE_LIBRARY_ROOT=<DRIVE_LIBRARY_ROOT>`）
  - `NLM_Hub`（`DRIVE_HUB_ROOT=<DRIVE_HUB_ROOT>`）
- **性能与防竞态设计**：后端 `/api/workspace/tree` 通过 `os.scandir`（直接复用 `WIN32_FIND_DATA`，避免在 Google DriveFS 大目录上逐项发起 RPC `stat`）并在 `asyncio.to_thread()` 中运行；前端通过 `AbortController` 与自增 `_wsReqSeq` 消除快速切换目录时的乱序覆盖。
- **在线预览与选材篮（Staging Basket）**：支持文本/代码文件前 32KB 在线安全预览（`/api/workspace/preview`）；勾选任意文件后，点底部按钮即可携带完整路径直达「官方 API & MCP 实验室」的 Quick-Add 模块或批量导入任意学习主题。

### 2. 右侧 6 大业务标签页
1. **额度总览**：展示全池平均 5h/周剩余率与单账号双进度条卡片（含 Ch1/Ch2 状态、重置倒计时与 22 项动作关键算力成本标签）。
2. **官方 API & MCP 实验室**：内置 Section A 公网连通探测 + 7 工具 Schema 展开浏览器 + 分步自检表；Section B 多通道 Quick-Add（文件/URL/内联笔记一键写入新本或现有本）；Section C 交互式 `tools/call` 调试器；Section D 本机 Antigravity MCP 注册监控。
3. **主题与批量协作**：管理统一学习主题与 Cloud Drive 文件夹映射、触发跨账号 Editor 共享、全多选下发 11 类 Studio 与 Chat 批任务。
4. **任务调度队列**：查看 `pending`/`waiting_quota`/`running`/`deferred_later`/`done`/`failed`/`canceled` 队列、实测 5h 扣减与产物云盘路径，支持取消、重试和手动触发调度 Tick。
5. **Google 云盘中枢**：实时浏览 `01_Inbox` 投递箱、`<DRIVE_LIBRARY_ROOT>` 资料库（勾选直接入库并一键生成学习套装），以及手动热备份数据库。
6. **账号台账与策略**：维护 6 Ultra + Pro/Plus/Free 台账、订阅到期倒计时、CDP 端口分配、`tier_policy`/`coupling_mode`/防风控延迟区间/`WORKSPACE_ROOT`/`official_proxy_url` 等全局配置。

## 二、后端 FastAPI 路由分组总览

| 路由前缀 | 核心模块 | 关键端点与功能 |
| :--- | :--- | :--- |
| `/`, `/api/health`, `/api/dashboard`, `/api/settings`, `/api/export/json` | `app/main.py` | 首页服务、健康检查、全局 KPI 聚合、全局设置读写与 JSON 全库导出 |
| `/api/accounts/*` | `app/api/accounts.py` | CRUD 账号、`/login`、`/oauth`、`/oauth-redirect`（302 直跳）、`/open-browser`（独立 Chrome）、`/capture-cdp`（CDP 提取 Cookie）、`/import-cookies-raw`（cURL/Cookie 导入）、`/poll-quota`、`/poll-all` |
| `/api/workspace/*` | `app/api/workspace.py` | `/roots`、`/tree`（全目录浏览+关键词搜索）、`/preview`（安全截断文本预览） |
| `/api/official/*` | `app/api/official.py` | `/status`、`/upload-client-secret`（自动提取并回填 `project_id`）、`/probe`、`/rest/verify`、`/mcp/call`、`/notebooks`、`/sources`、`/quick-add` |
| `/api/topics/*`, `/api/notebooks/*` | `app/api/inventory.py` | 主题 CRUD、`/{id}/share-all`（全池共享 Editor）、`/{id}/ingest`（校验安全白名单并入队）、`/notebooks/sync-all` |
| `/api/tasks/*` | `app/api/tasks.py` | 队列过滤查询、单任务与批量任务创建、取消/重试与手动 `/tick` |
| `/api/drive/*` | `app/api/drive.py` | `/inbox`、`/library`、`/topics`（最近归档产物）与 `/backup-now` |

## 三、本机 Antigravity MCP 服务（`notebooklm-fleet`）

除了面向个人账号的 Google 托管 Remote MCP 外，项目在 `app/mcp_server.py` 还运行了一套基于 **FastMCP (`fastmcp`) + Stdio** 的本地 MCP 聚合服务（强制所有日志输出至 `sys.stderr`，确保 `stdout` 纯净 JSON-RPC 零污染），已注册在 `~/.gemini/config/mcp_config.json` 并配属对应 Skill（`.agents/skills/notebooklm-fleet/SKILL.md`）：

- **监控类**：`fleet_quota_overview`、`fleet_poll_quotas`、`fleet_list_accounts`
- **编排类**：`fleet_list_topics`、`fleet_create_topic_and_ingest`、`fleet_enqueue_batch`
- **运维类**：`fleet_task_status`、`fleet_control_task`、`fleet_add_account`、`fleet_open_account_browser`

借由本地 MCP，在 Antigravity 对话中即可一句指令完成“查询全部 6 个 Ultra 剩余额度 → 选择最空闲账号批量生成音频与测验 → 查看云盘归档路径”。
