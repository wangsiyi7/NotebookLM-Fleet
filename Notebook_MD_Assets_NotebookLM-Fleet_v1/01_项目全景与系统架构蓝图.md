# 01 · NotebookLM-Fleet 项目全景与系统架构蓝图

## 一、定位与核心目标

**NotebookLM-Fleet** 是面向多 Google AI 账号（主力 **6 个 Ultra**，兼容扩展 **Pro / Plus / Free**）的一体化监控、调度与协作中枢，解决单账号频繁触达 5 小时/周限额、多号资料割裂、以及手工重复生成 Studio 产出的痛点。

核心设计目标可概括为四点：
1. **双窗口量化监控**：实时采集并持久化每个账号的 **5 小时（Five Hour）** 与 **周滚动（Weekly）** 已用/剩余百分比、窗口重置时间以及 22 种动作的精细算力成本（`estimated_cost_percent`）和延时槽位（`remaining_deferred_artifact_generations`）。
2. **三通道能力协同**：结合 2026 年 11 月 Google 开放的 **官方 Gemini Notebook Personal Beta API/MCP**、功能全覆盖的 **`notebooklm-py`（Channel 2）**，以及**独立端口隔离的 Chrome CDP（Channel 3）**。
3. **Google Drive 中枢统一沉淀**：以个人主力账号（`ultra-1@example.com`）本地挂载盘 `<DRIVE_HUB_ROOT>` 为单一事实源与归档中枢，所有主题、原始资料、Studio 产物（音频、视频、PPT、测验、闪卡、思维导图、报告）与数据库快照统一归档。
4. **双入口联动**：既提供纯中文暖纸感 Web 控制面板（`http://127.0.0.1:8765`，带左侧全工作区直调侧边栏），也提供向 Antigravity / Gemini CLI 暴露的本地 Stdio MCP 服务（`notebooklm-fleet`，10 个工具）。

## 二、三通道架构对照与自动路由（`CapabilityRouter`）

| 通道 | 协议 / 技术栈 | 擅长能力 | 局限与回退机制 |
| :--- | :--- | :--- | :--- |
| **Channel 1** | Google 官方 API v1 (`notebook.googleapis.com/v1`, `/upload/v1`) & Remote MCP (`notebook.googleapis.com/mcp`) | OAuth 2.0 稳定鉴权（无 Cookie 过期风险）、建本/查本/改名、`is_owner` 过滤、导入文本/MD/URL 及最大 200 MiB 二进制文件上传 | 个人账号公测期不暴露 5h/周额度、Studio 生成、Chat 对话及共享 Editor 接口 |
| **Channel 2** | `notebooklm-py >= 0.8.6`（按账号完全隔离的 `storage_state.json`） | 全量能力：实时 5h/周用量 RPC、22 类操作成本探测、全 11 类 Studio 生成（含 `--later`）、Chat 问答、跨号共享 Editor | 依赖浏览器会话 Cookie，需要定期刷新保活；严禁多个账号混用同一 Cookie Jar |
| **Channel 3** | 本机原版 Chrome `--user-data-dir` + `--remote-debugging-port` | 人工可视化接管、无自动化特征登录、通过 CDP WebSocket 直接无损提取 Cookie 到 Channel 2 | 面向人机协同与首登激活，非后台高频批量通道 |

`CapabilityRouter`（位于 `app/adapters/router.py`）负责在 Ch1 与 Ch2 间动态切换：当全局开启 `official_api_enabled` 且账号已持有有效 OAuth Token 时，优先把 `list_notebooks`、`create_notebook`、`ingest_url`、`ingest_text` 与 `ingest_file` 路由至官方 API；若官方端失败且账号已配置 Ch2 会话，自动记录告警并回退至 `notebooklm-py`。

## 三、工程目录拓扑（`<NotebookLM-Fleet>`）

- **`app/config.py`**：基于 `pydantic-settings` 管理 `.env` 与测试环境覆盖变量（`FLEET_DATA_DIR`、`FLEET_DB_PATH`、`FLEET_DISABLE_WORKERS`），默认绑定 `WORKSPACE_ROOT=<WORKSPACE_ROOT>`、`DRIVE_HUB_ROOT=<DRIVE_HUB_ROOT>`。
- **`app/schema.sql` & `app/db.py`**：SQLite WAL（外键开启、`busy_timeout=30000`）异步数据层，首次启动自动建表、写入默认策略并预置主账号 `ultra-1`（`ultra-1@example.com`，CDP 端口 `9222`）。
- **`app/adapters/`**：外部能力适配层，涵盖 `official_api.py`、`official_mcp_client.py`、`nlm_py_adapter.py`、`browser_takeover.py`、`router.py`。
- **`app/core/`**：领域核心引擎，包括 `quota_poller.py`（额度采集+备份）、`scheduler.py`（分档调度+防风控串行）、`coupling.py`（跨号共享+镜像）、`drive_hub.py`（云盘目录与安全边界）。
- **`app/api/`**：FastAPI REST 接口层，拆分为 `accounts.py`、`inventory.py`、`tasks.py`、`drive.py`、`workspace.py`、`official.py`。
- **`app/main.py` & `app/mcp_server.py`**：Web 应用生命周期入口（含重启卡死任务恢复、无缓存首页与后台协程启停）及 Stdio MCP 服务端。
- **`web/index.html`**：单文件原生前端控制面板（零构建依赖，左侧工作区树 + 选材篮 + 右侧 6 大业务标签页）。

## 四、7 张核心 SQLite WAL 数据表模型

1. **`accounts`**：账号台账，记录 `alias`、`email`、`tier`（ultra/pro/plus/free）、独立的 `nlm_profile` 与 `chrome_profile_dir`、`cdp_port`、`is_hub_master`、Ch1/Ch2 双认证状态、`notebook_limit`/`source_limit` 上限与到期提醒。
2. **`quota_snapshots`**：时间序列额度快照，记录 5 小时窗口与周窗口使用率/剩余率/重置时刻、`is_exhausted` 以及按动作明细 JSON（`actions_json`）。
3. **`topics`**：与具体账号解耦的统一“学习主题”，绑定唯一的云盘目录 `02_Topics/<sanitized_name>`、`master_account_id` 和协作策略 `coupling_mode`。
4. **`notebooks`**：各账号远程笔记本台账，通过 `UNIQUE(account_id, remote_notebook_id)` 去重，支持关联 `topic_id`、`is_master` 与已共享邮箱列表 `shared_emails_json`。
5. **`tasks`**：统一任务队列，跟踪 `batch_id`、`task_type`、`payload_json`、`tier_requirement`、`priority`、状态机（`pending` → `running` → `done`/`failed`/`deferred_later`/`waiting_quota`/`canceled`）、预估扣减（`est_cost_pct`）与执行前后实测 5h 差值（`actual_delta_5h_pct`）。
6. **`artifacts`**：Studio 生成物与 Chat 导出的云盘归档记录，关联主题、执行账号、任务及云盘路径 `local_drive_path`。
7. **`app_settings`**：键值配置表，持久化策略参数、工作目录、可选代理 `official_proxy_url` 以及最近一次公网 MCP 探测快照 `official_mcp_last_probe_json`。

## 五、Google Drive Hub 目录规范

主力网盘目录固定结构如下（程序绝不读写 `NLM_Hub` 之外任何现有云盘目录做写入改动）：

```text
<DRIVE_HUB_ROOT>\
├── 00_System\backups\      # 在线 sqlite3.backup 热备份（保留最近 14 份）
├── 01_Inbox\               # 待整理/导入的资料投递箱
├── 02_Topics\<主题名称>\
│   ├── Sources\            # 该主题源文件镜像（支持跨账号镜像重构）
│   └── Artifacts\          # 各账号产出的音频/视频/PPT/测验/导图/Chat MD
└── 03_Exports\             # 未归属特定主题的临时文本导出
```
